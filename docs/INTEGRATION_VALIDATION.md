# 통합 검증 결과 — 2026-09-21

## 완료

- 양쪽 Git HEAD가 통합 이력의 조상임을 확인. 원본 커밋을 재작성하지 않음.
- 기존 작업 파일과 운영 파일을 앱별로 복사한 뒤 SHA-256으로 비교: SRS 9,197개 / 1,191,854,976 bytes, 이슈 116개 / 102,564,182 bytes, 불일치 0개. 캐시·Git DB·최상위 관리 파일은 이 비교에서 제외.
- 기존 SRS 테스트와 통합 테스트 합계 101개 통과.
- 통합 실행기 18개 테스트: 메뉴 분기, 잘못된 입력, 외부 작업 폴더 실행, 실제 Windows PowerShell 인자 보존, 종료 코드 전달.
- 실제 Chromium으로 두 앱의 PDF 변환 함수를 실행. 합성 HTML을 각각 PDF 1페이지로 생성하고 텍스트 추출로 내용 확인.
- 예약 작업 두 개의 XML을 백업하고 작업 디렉터리만 `apps/srs-spec`으로 변경. 변경 전후 XML 비교로 다른 설정이 유지됨을 확인.
- 두 앱의 실제 설정, 환경 파일, 내부 로그와 운영 산출물이 Git 추적 대상에 포함되지 않음을 확인.
- 별도 리뷰에서 발견한 PowerShell 따옴표 손상 문제를 재현 테스트 후 수정.

## 검증 범위의 한계

- 실제 ALM 서버를 대상으로 전체 수집·배포·메일 발송은 실행하지 않음.
- 보호된 실제 설정의 내용을 열람하지 않으므로 그 안의 절대 경로까지 확인한 것은 아님.
- 실제 예약 시각의 장시간 운영, 대용량 이슈 PDF, 네트워크 실패 후 복구는 별도 운영 확인 필요.
- 이슈 앱의 부분 실패/알림/수집 완전성 관련 기존 개선점은 `AUTOMATION_ROADMAP.md`에 기록. 통합 결함과 구분함.

## 복구

원본 두 작업 폴더와 이력 bundle을 유지한다. 예약 작업의 변경 전 XML은 로컬 `.migration/scheduled-tasks/`에 있다. 운영 검증을 마치기 전에는 원본 폴더와 기존 이슈 저장소를 삭제하지 않는다. 이후 개발과 수동 실행은 통합 프로젝트에서만 수행한다.
