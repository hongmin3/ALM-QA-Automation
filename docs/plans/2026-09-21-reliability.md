# 관찰 모드 선행 신뢰성 개선 계획

사용자 요청: 기존 개선 항목 구현. 알림 활성화 전에 수집·분석 결과를 저장하는 관찰 모드로 검증한다.
사양: SPEC.md의 REQ-SRS-004, REQ-OPS-001/002, REQ-OBS-001.

1. SRS 영역: 분할 누락 검증·설정 연결·배포 중 실패 복구. 실패 주입 테스트를 먼저 추가한다.
2. 이슈 영역: 실행별 staging/잠금/manifest·상태·이전 결과 보존. 합성 API와 파일 실패 주입으로 재현 후 수정한다.
3. 관찰 영역: 명시적 저장 결과 입력을 받아 후보·실행 기록을 저장한다. 반복과 손상 입력을 테스트한다. 실수집·메일 발송·스케줄러 변경은 하지 않는다.
4. 모든 결과 통합 후 기존 회귀, 실제 CLI 합성 입력, spec-lint, diff 검토를 수행한다.
5. SPEC/CHANGELOG/progress/사용법에 실제 완료 범위와 남은 운영 검증을 기록한다.

각 영역은 서로 다른 파일을 소유하여 병렬 작업한다. 실행 로직 변경은 이 개선 요청 범위에 한정한다. 보호된 실사용 설정은 열람하지 않는다. 새 의존성은 추가하지 않는다.
